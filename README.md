# Splendor Duel Table

갤럭시·아이폰 어디서든 **브라우저로 접속**해 친구와 실시간으로 플레이하는 2인용 스플렌더입니다.
앱 설치가 필요 없고, 각자 자기 언어(한국어 · Español · English)로 화면을 봅니다.

## 두 가지 방법 중 하나를 고르세요

| | **Render 배포 (권장)** | GitHub Pages |
|---|---|---|
| 로그인 · 친구 목록 | 있음 | 없음 |
| 친구 초대 | 친구 목록에서 버튼 한 번 | 초대 코드를 매번 주고받아야 함 |
| 끊겼을 때 | 다시 열면 자동 복귀 | 코드 재교환 |
| 준비 | 아래 5분 | Settings → Pages |

로그인과 친구 기능은 서버가 있어야 동작합니다. GitHub Pages는 정적 파일만 서비스하므로
그쪽 주소에서는 로그인 화면이 아예 나오지 않고 초대 코드 방식만 보입니다.

## Render 배포 (5분, 무료)

1. [render.com](https://render.com) 에 GitHub 계정으로 로그인합니다.
2. **New → Blueprint** 를 누르고 이 저장소(`splandor`)를 고릅니다.
3. **Apply**. `server/render.yaml` 이 설정을 알아서 채웁니다. 계정 비밀번호를 지키는
   `SPLENDOR_SECRET` 도 Render가 자동으로 만들어 고정해 줍니다.
4. 몇 분 뒤 `https://splendor-xxxx.onrender.com` 주소가 생깁니다. **이 주소가 게임 주소입니다.**

무료 플랜은 15분 동안 아무도 안 쓰면 잠들었다가 첫 접속에 30~60초 걸려 깨어납니다.
게임 중에는 영향이 없습니다.

## 쓰는 법

1. **로그인**: 원하는 닉네임과 비밀번호를 넣으면 그대로 가입됩니다. 같은 쌍으로 언제든 다시 들어옵니다.
2. **친구 추가**: 메인 화면 **오른쪽 위의 사람 모양 버튼**을 누르면 친구 서랍이 열립니다.
   내 친구 코드를 친구에게 보내고, 받은 코드를 넣고 `추가` 를 누릅니다. 한 번만 하면 됩니다.
3. **대결**: 친구가 접속 중이면 초록 불이 켜지고 버튼에 숫자 배지가 붙습니다.
   `대결 신청` 을 누르고 친구가 수락하면 시작됩니다.
4. **끊겼을 때**: 창을 닫아도 판은 남아 있습니다. 같은 계정으로 다시 열면 그 자리로 돌아갑니다.
   상대가 1분 넘게 돌아오지 않으면 `기다리지 않고 승리하기` 가 나옵니다.
5. **나가기**: 게임 화면의 `×` 는 확인을 한 번 묻고, 확인하면 **게임이 끝나고 상대가 승리**합니다.
   잠시 자리를 비우는 것과 구분됩니다.

계정은 데이터베이스에 저장되지 않습니다. 닉네임과 비밀번호를 키로 해싱해 신원을 만들기 때문에,
서버가 재시작돼도 같은 닉네임과 비밀번호로 그대로 들어올 수 있습니다. 친구 목록은 각자 기기에 남습니다.

## 들어 있는 것

- 2인 규칙 그대로: 보석 4개씩 · 황금 5개 · 귀족 3명 · 15점이면 그 라운드까지
- 카드 90장 각각의 일러스트와 귀족 초상을 코드로 그립니다 (이미지 파일 없음)
- 카드와 보석이 실제로 움직입니다: 덱에서 나와 뒤집히고, 은행과 내 판 사이를 날아다니고,
  카드를 사면 값을 치른 보석이 먼저 은행으로 돌아갑니다
- 소리도 전부 코드로 합성합니다. 보석마다 음정이 달라 3개를 집으면 화음이 되고,
  상대의 수는 저역 필터를 거쳐 테이블 건너편처럼 들립니다. 상단 스피커 버튼으로 끕니다
- 컴퓨터 상대와 배우는 9단계 튜토리얼, 한 기기에서 번갈아 하는 모드, 진행 중인 판 이어하기

## 파일

| 파일 | 역할 |
|---|---|
| `index.html` | 화면, 번역, 연결. 게임의 본체 |
| `game.js` | 규칙 엔진. 브라우저와 서버가 같은 코드를 씁니다 |
| `art.js` | 카드 일러스트·귀족 초상·카드 뒷면을 SVG로 그립니다 |
| `fx.js` | 움직임, 합성 사운드, 진동 |
| `server/` | 계정·친구·방·재접속을 처리하는 서버 |

## 직접 돌려보기

```bash
cd server
npm install
npm start    # http://localhost:3000
npm test     # 규칙 엔진 200판 + 계정·친구·재접속·나가기 통합 테스트
```

## GitHub Pages (로그인 없이)

메인 화면의 `서버 없이 친구와 직접 연결` 은 서버가 없을 때만 나옵니다. 서버가 있으면
친구 목록과 방 코드가 같은 일을 하므로 화면에서 빠집니다.

서버 없이 쓰려면 **Settings → Pages → Branch: main, / (root)** 로 저장하면
`https://youngduckcrab.github.io/splandor/` 가 열립니다. 이 주소에서는 튜토리얼,
한 기기 모드, 초대 코드 직접 연결만 됩니다.
