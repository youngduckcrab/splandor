# Splendor Duel Table

갤럭시·아이폰 어디서든 **브라우저로 접속**해 친구와 실시간으로 플레이하는 2인용 스플렌더입니다.
앱 설치가 필요 없고, 각자 자기 언어(한국어 · Español · English)로 화면을 봅니다.

## 게임 주소 켜기 (한 번만)

저장소 **Settings → Pages → Branch** 에서 **main** 과 **/ (root)** 를 고르고 **Save**.
1~2분 뒤 아래 주소가 열립니다.

```
https://youngduckcrab.github.io/splandor/
```

이 주소를 친구에게 보내면 됩니다. 로그인도 서버도 필요 없습니다.

## 친구와 연결하기

초대 코드를 메신저로 한 번씩 주고받으면 두 폰이 직접 연결됩니다.

1. **방장**: 이름 입력 → `초대 코드 만들기` → `초대 코드 보내기` 로 카카오톡·WhatsApp에 전달
2. **참가자**: `초대 코드 받았어요` → 코드 붙여넣기 → `응답 코드 만들기` → 생긴 코드를 방장에게 전달
3. **방장**: 2단계 칸에 응답 코드 붙여넣기 → `연결하기`

연결이 끊기면 상단 배너의 `다시 연결` 로 코드를 다시 교환합니다. 진행 중인 판은 방장 폰에 남아 있습니다.

## 들어 있는 것

- 2인 규칙 그대로: 보석 4개씩 · 황금 5개 · 귀족 3명 · 15점이면 그 라운드까지
- 카드 90장 각각의 일러스트와 귀족 초상을 코드로 그립니다 (이미지 파일 없음)
- 카드와 보석이 실제로 움직입니다: 덱에서 나와 뒤집히고, 은행과 내 판 사이를 날아다니고,
  카드를 사면 값을 치른 보석이 먼저 은행으로 돌아갑니다
- 소리도 전부 코드로 합성합니다. 보석마다 음정이 달라 3개를 집으면 화음이 되고,
  상대의 수는 저역 필터를 거쳐 테이블 건너편처럼 들립니다. 상단 스피커 버튼으로 끕니다
- 컴퓨터 상대와 배우는 9단계 튜토리얼, 한 기기에서 번갈아 하는 모드, 진행 중인 판 이어하기

## 파일

| 파일 | 역할 |
|---|---|
| `index.html` | 화면, 번역, 연결. 게임의 본체 |
| `game.js` | 규칙 엔진. 브라우저와 서버가 같은 코드를 씁니다 |
| `art.js` | 카드 일러스트·귀족 초상·카드 뒷면을 SVG로 그립니다 |
| `fx.js` | 움직임, 합성 사운드, 진동 |
| `server/` | 방 코드 4글자로 노는 선택적 서버 모드 |

## 서버 모드 (선택)

직접 연결이 통신사 망 때문에 안 될 때를 위한 대안입니다. 없어도 게임은 됩니다.

```bash
cd server
npm install
npm start    # http://localhost:3000
npm test     # 규칙 엔진 무작위 200판 검사
```

[Render](https://render.com) 에 배포하려면 New → Blueprint 로 이 저장소를 연결하면 `server/render.yaml` 이 알아서 설정합니다.
